# PodJS

An open source podcast app built with [Next.js](https://nextjs.org/), [MobX](https://mobx.js.org/), and [Chakra UI](https://chakra-ui.com/).

**[Live Demo](https://podjs.vercel.app)**

## Tech Stack

- **Framework:** Next.js
- **State Management:** MobX
- **UI Library:** Chakra UI
- **Language:** TypeScript
- **API:** iTunes Search API

## Getting Started

```bash
yarn install
yarn dev
```
